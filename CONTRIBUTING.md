# Contributing

Small fixes with regression tests are welcome. Open an issue before adding a
new manifest format, audit policy, dependency or integration. Preserve complete
validation, explicit half-open boundaries, exact integer counts and privacy
by default. Do not reinterpret a pass as proof of independence or no leakage.

Run the commands in README.md. Include a failing test demonstrating a bug before
the fix, and explain what the result does and does not establish. Tool-assisted
contributions are welcome; contributors remain responsible for checking their
work and answering questions truthfully. Do not include private datasets,
credentials or identifying reports in examples or issues.
